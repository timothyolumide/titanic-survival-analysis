# Titanic Survival Analysis

## What I did
- Loaded the Kaggle Titanic dataset
- Filled 177 missing ages with the median
- Grouped Passengers by sex, class and age
- Made three charts
## Findings

- Women: 74% survived. Men: 19%.
- 1st class: 63%.   2nd class: 47%. 3rd class: 24%.
- Children: 58%. Seniors: 23%.

  Note: the Cabin column had 687 missing values, so I did not use it.
  
  ## Run it
  
  1. Download train.csv from Kaggle Titanic competition and put it in the same folder.
  2. Install: pip install pandas matplotlib
  3. Run: python titanic_analysis.py
